# counter — подсчёт по камерам (следующий этап)

Здесь будет сервис, который читает RTSP-потоки из `config/config.yaml` и шлёт в API
те же события, что сейчас шлёт симулятор (формат — в главном README).

План:
1. `entrance` — YOLO находит людей, ByteTrack даёт им ID, пересечение линии у двери → `entry` / `exit`.
2. `hall` — зоны-многоугольники по отделам → `zone_visit` (время в зоне); продавец рядом с покупателем → `consult`.
3. `shelves` — снимок раз в 15 минут, если в кадре нет людей → vision-модель в Ollama → `shelf`.

Правила: кадры не сохраняются, лица не распознаются, в Ollama не уходят кадры с людьми.

Когда сервис будет готов: в `.env` поставить `COMPOSE_PROFILES=cameras` и раскомментировать `counter` в `docker-compose.yml`.
